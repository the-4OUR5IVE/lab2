# Octagon Book API (Интеграционный модуль работы с БД)

Веб-приложение на базе **FastAPI**, **SQLAlchemy** и **PostgreSQL** для управления каталогом книг и категорий.

## Настройка переменных окружения (.env)

Для корректного подключения к базе данных создайте в корне проекта файл `.env` и заполните его следующими переменными:

```ini
DB_HOST=localhost
DB_PORT=5432
DB_NAME=octagon_db
DB_USER=octagon
DB_PASSWORD=12345
```

**Пояснение параметров:**
* `DB_HOST` — адрес сервера, на котором запущена СУБД PostgreSQL (для локальной разработки в WSL используется `localhost`).
* `DB_PORT` — сетевой порт для подключения к PostgreSQL (стандартный порт по умолчанию — `5432`).
* `DB_NAME` — название рабочей базы данных, в которой будут созданы таблицы (`octagon_db`).
* `DB_USER` — имя пользователя базы данных с правами на создание таблиц и работу с данными (`octagon`).
* `DB_PASSWORD` — пароль указанного пользователя БД для аутентификации.

## Инструкция по запуску проекта

1. **Клонируйте репозиторий и перейдите в директорию проекта:**
   ```bash
   git clone <ссылка_на_ваш_репозиторий>
   cd lab2
   ```

2. **Создайте и активируйте виртуальное окружение:**
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   ```

3. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Инициализируйте базу данных тестовыми данными (опционально):**
   ```bash
   python3 app/init_db.py
   ```

5. **Запустите веб-сервер FastAPI:**
   ```bash
   uvicorn app.main:app --reload
   ```

6. **Откройте документацию API:**
   Перейдите в браузере по адресу [http://127.0.0](http://127.0.0) для тестирования эндпоинтов через Swagger UI.
